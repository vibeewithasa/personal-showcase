# Owner images

Use this folder for your favicon, optional logo/portrait, SEO image or legacy manual-project assets. Owner/manual paths use safe names such as images/my-logo.webp. See docs/CUSTOMIZATION.md.

Photographic sessions belong in public/sessions/<folder>, where camera filenames, Unicode and spaces are supported automatically. See docs/SESSIONS.md.

The previous graphic demo studies remain only under tests/fixtures/images so legacy behavioral tests still work after content replacement. They are original MIT sample graphics, not client projects.

Everything under public is published. Use trusted, licensed assets and approved web copies; remove private EXIF/GPS data before adding originals here.
