# Demonstration artwork

All SVG files and the sharing PNG in this folder are original geometric/typographic sample artwork created for this template. They depict fictional, self-initiated projects, not client work, real events, photographs, or third-party brands. They may be reused and modified under the repository's MIT license.

Replace them with your own licensed work before publishing a personal portfolio. Use descriptive lowercase filenames, hyphens instead of spaces, and paths such as `images/my-project.webp` in `src/content/portfolio.json`. Supported extensions: avif, gif, jpg, jpeg, png, svg, webp, ico. Only use trusted SVG files because SVG is active content when opened directly.

`share.png` is an original 1200×630 sharing-image example; replace it with a JPEG or PNG showing your own identity or work. `favicon.svg` is a generic mark, not a third-party logo. The SVG text uses system font stacks and bundles no font software.
